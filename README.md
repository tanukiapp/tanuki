# Tanuki backend microservices

## Development

### Fresh start or update

To get a fresh copy of OpenAPI schemas, run:

```
npm run start
```

This will download updated OpenAPI schemas, needed for validating sources.

### Catalog service

```
cd services/catalog
npm install
npm run dev
```

### Schedule service

```
cd services/schedule
npm install
npm run dev
```

## Testing

```
npm test
```
